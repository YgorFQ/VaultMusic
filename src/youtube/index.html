    Conectar ao YouTube

    Para buscar, informe uma chave da YouTube Data API. Para acessar sua conta, importe também o JSON OAuth de um aplicativo para computador.

    A senha é digitada somente na página oficial do Google. As credenciais e os tokens são protegidos pelo Windows para este usuário. Vincular a API não conecta automaticamente o navegador ao YouTube.
